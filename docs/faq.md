# 附录 常见问题

---

### Q1：不会写代码能做吗？

能。整套方案没有任何代码，只需要新建文件夹、复制模板、改几个名字和路径。

### Q2：聊了几个月，会不会越来越慢？

不会。开场只读 `MEMORY.md` 和最新 2 篇日记，更早的日记只在提到时才搜索。`MEMORY.md` 超过 200 行时按规则精简即可。

### Q3：同一天在不同窗口聊天，记忆会乱吗？

不会。所有窗口共用同一个记忆目录，同一天的内容都按时间追加到同一篇日记里。

### Q4：直接关机了还是漏记怎么办？

让一个普通 AI 助手读取平台本地的聊天记录，把漏掉的内容补进当天日记即可。

### Q5：为什么不用定时任务自动整理？

定时任务在关机时同样不会运行，而且会产生大量中间文件。边聊边写已经覆盖了绝大多数情况，偶尔的遗漏手动补录更简单。

### Q6：记忆文件能上传到 GitHub 吗？

**不建议上传到公开仓库**，里面是你的私人聊天内容。需要备份时，拷到 U 盘或私人网盘即可。

### Q7：可以用在 macOS 或 WorkBuddy 以外的平台吗？

可以：
- **macOS 用户**：把模板和 `SKILL.md` 里的 `D:\AgentMemory\` 换成 `/Users/<你的用户名>/AgentMemory/`，`D:\AgentMemory-backups\` 换成 `/Users/<你的用户名>/AgentMemory-backups/`（建议写完整绝对路径，不要写 `~`）；WorkBuddy 插件目录在 `~/.workbuddy/plugins/` 下（访达按 `Cmd + Shift + .` 显示隐藏文件夹）。
- **其他 Agent 平台**：只要平台支持 **Skill（或类似的工具说明文件）** 和 **本地文件读写**，把模板里的路径和插件元信息换成对应平台的格式即可。欢迎提 PR 补充其他平台的适配说明。

### Q8：Agent 会不会在聊天中把自己的设定改坏？

模板中的人设卡和 Skill 都写明了禁止修改自身配置。想优化设定时，请另开一个普通 AI 助手来改，详见 [第 4 章](./chapter4-evolve.md)。
