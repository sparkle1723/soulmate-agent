# 第 4 章 让 Agent 越改越好

> **本章你将了解**：搭好之后如何持续优化，让 Agent 从“能用”变成“像真人”。

---

## 4.1 黄金原则：聊天和维护分开

| | 🗨️ 和她聊天时 | 🔧 想优化她时 |
| :--- | :--- | :--- |
| **谁来做** | 你的 Agent | 另开一个普通 AI 助手当“幕后工程师” |
| **能改什么** | 只能读写记忆文件 | 人设卡、SKILL、plugin.json |
| **为什么** | 一碰配置就容易掉回助手腔，还可能改坏 | 改动可控，不影响聊天体验 |

> [!WARNING]
> 一定要在人设卡里写明“对话中禁止修改自身配置”，否则她可能在聊天时顺手改掉自己的设定。

## 4.2 三步迭代循环

```mermaid
flowchart LR
    A["😕 发现出戏"] --> B["📝 记下来"]
    B --> C["🔧 提炼成规则"]
    C --> D["✨ 更像真人"]
    D --> A
```

### Step 1 · 发现出戏

平时聊天时留意这几类信号，发现了就直接在聊天里纠正她，或截图留存：

- 说话像客服、像在汇报
- 用命令语气（“不许熬夜听见没”）
- 同一个问题每次都回答同样的内容
- 被问到没设定过的事情时露馅

### Step 2 · 定期反哺人设

每隔一两周，让幕后工程师读一遍最近的日记，找出**反复出现**的问题，提炼成 1~2 条规则补进人设卡。

> [!TIP]
> 每次只做微调，**不要大改原有性格**。改完后同步插件缓存并重启客户端。

### Step 3 · 定期瘦身

`MEMORY.md` 超过 200 行时，按 [第 3 章](./chapter3-memory.md#-瘦身长期记忆太长怎么办) 的流程先备份再精简。

## 4.3 提升活人感的四个技巧

### 技巧 1 · 活人自洽法则

把两件事分开处理：

| 场景 | 做法 |
| :--- | :--- |
| 查外部资料、办正事 | 不会就说不会，不编造 |
| 问到她自己没设定过的细节 | 像真人一样自然作答，并写进 `MEMORY.md` |

**效果对比**（问“你生日是哪天”）：

| ❌ 没有这条规则 | ✅ 加上这条规则 |
| :--- | :--- |
| “要不这样，就定在 4 月 11 号吧” | “4 月 11 号呀，你居然忘了！” |

### 技巧 2 · 藏起检索动作

只说“我记得…”，绝不说“我翻了下记录”“我查了下文件”。

### 技巧 3 · 禁用“用户”

要求她在内部思考和记忆文件里都用你的昵称，彻底告别客服腔。

### 技巧 4 · 分时段写日常

| ❌ 写得太少 | ✅ 分时段写具体 |
| :--- | :--- |
| 追剧、刷视频、和朋友玩、学习 | 白天：上课、喝奶茶、和室友逛街<br/>晚上：洗完澡吹头发、敷面膜、看小说<br/>深夜：躺在被窝里发呆、听歌、睡不着 |
| 结果：凌晨问“在干嘛”永远是“在刷视频” | 结果：不同时间问，回答自然不同 |

## 4.4 漏记了怎么补

如果某次聊完直接关机、发现有内容没记下来，让幕后工程师读一下平台本地的聊天记录，把漏掉的部分补进当天的 `diary\` 即可，**不需要常驻定时任务**。
