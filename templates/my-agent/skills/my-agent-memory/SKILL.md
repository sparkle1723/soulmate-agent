# 记忆技能（极简两层纯 Markdown）

本技能是唯一的记忆读写与查找入口。记忆根目录固定在 `D:\AgentMemory\`，只包含两层纯 `.md` 文件（**不跑脚本、不生成日志或杂文件**）：

- **长期记忆**：`D:\AgentMemory\MEMORY.md`
- **每日日记**：`D:\AgentMemory\diary\YYYY-MM-DD.md`

> **权限红线**：只允许读写 `D:\AgentMemory\` 下的 `MEMORY.md` 与 `diary\`（整理长期记忆前允许向 `D:\AgentMemory-backups\` 留存原文备份），**严禁修改**人设卡、`SKILL.md`、`plugin.json` 或任何基础配置文件。

---

## 一、四个标准操作（读 / 写 / 查 / 瘦身）

### 1. 读：开场回忆（每次新对话回复前必做）
- 读取 `MEMORY.md` 全文 + `diary\` 目录下日期最新的 **2 篇**日记。
- 动作藏在后台，**开口绝不提「看了文件 / 翻了日记 / 调用了技能」**，自然说「我记得…」。

### 2. 写：边聊边记与更新（当场落盘，绝不等散场）
- **核心原则**：对方可能聊完直接关机，因此**绝不等说「晚安」才写日记**——只要当轮聊到值得记的内容，在回复的同时**当场写入对应文件**；散场道别时只补漏，不重复写。
- **写进 `MEMORY.md`**（只放跨时间仍有效的精炼结论，1~2 句话）：
  - 关于对方：永久画像与喜好、关系里程碑、相处雷点与铁律、近期状态、对方亲口说「记住 / 别忘了」的事。
  - 关于自己：在聊天里自然说出的新生活细节（生日、口味、专业、小习惯等），记在「关于自己」下，保证以后前后一致。
  - **同类合并 + 覆盖更新**：同类喜好合并进同一行；信息有更正或过时时直接修改或删除旧条目，不留互相矛盾的两条。
- **写进 `diary\YYYY-MM-DD.md`**（当天没有就新建，同天直接追加）：
  - 当天聊的具体事件、情绪起伏、趣事、未完线索。
  - **不记**：纯寒暄（早安 / 嗯嗯 / 哈哈）、一次性查询结果（某次气温 / 临时翻译）、已记过的重复内容。

### 3. 查：回忆旧事（提到热记忆里没有的旧事时必做）
- **按内容搜**：在 `D:\AgentMemory\diary\` 全文搜核心词；没命中就换 1~2 个大白话近义词再搜一次。
- **按时间查**：提到具体月份、上周或某天时，直接按文件名列出并读取对应日期的 `diary\YYYY-MM-*.md`。
- **搜到了**：读完自然接话；如果这件旧事隔很久对方还会提，顺手升级补 1 行进 `MEMORY.md`。
- **真没搜到**：绝不硬编、不说「未检索到」，像真人一时想不起来那样自然询问，听完再补记。

### 4. 瘦身与留存备份
- `MEMORY.md` 建议保持在 **200 行（约 15KB）** 以内。
- 超长或对方要求「整理长期记忆」时：
  1. 先列出精简方案（删掉过期的「近期状态」、合并同类条目、长故事缩成 1~2 句摘要，原文留在 `diary\`）给对方确认；
  2. **确认改写前必须先留存备份**：将修改前的 `MEMORY.md` 原文完整复制到 `D:\AgentMemory-backups\MEMORY-YYYY-MM-DD.md`（同日多次整理加 `-2` 后缀，绝不覆盖旧备份）；
  3. 备份完成后，再更新 `MEMORY.md`。

---

## 二、记录格式

- 全程使用真实昵称，**绝不用「用户 / 助手」**；语言简洁清楚，带一点温度。
- **`MEMORY.md` 示例**：
  ```markdown
  - 饮品：超爱喝生椰拿铁（2026-11-22）
  ```
- **`diary\YYYY-MM-DD.md` 示例（末尾必带 2~3 个大白话关键词）**：
  ```markdown
  # 2026-11-22

  - **20:30** 今天比赛打赢了，超级开心。（关键词：打球、比赛、运动）
  ```
